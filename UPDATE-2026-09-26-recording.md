# Обновление от 26 сентября 2026 года — запись сессий

На сайт добавлена запись сессий: для каждого посетителя сохраняются снимки страницы (скриншоты видимой части) и все клики с координатами. Всё это видно в вашей админке (`/admin` на Worker) во вкладке «Записи сессий».

## Что именно записывается

- Снимок видимой части страницы: при открытии, при кликах (не чаще раза в 2,6 с), при прокрутке до ~5/30/60/95% страницы. Максимум 15 снимков за сессию, JPEG шириной до 720 px.
- Каждый клик: время, координаты на странице и в окне, элемент (тег, id, классы), текст кнопки/ссылки, позиция прокрутки.
- Крупные прокрутки (время и процент страницы) — чтобы понимать, где листали.
- Сессия — одна вкладка браузера до 30 минут неактивности. Данные привязываются к Visitor ID из журнала посещений, заблокированные посетители не записываются.

Что НЕ записывается: содержимое полей ввода (снимок делается после клика, текст паролей/полей не собирается отдельно), движение мыши, нажатия клавиш. Камеры/микрофоны/clipboard по-прежнему не трогаются.

Запись работает только в современных браузерах (как основная версия сайта). В режиме совместимости (старые Safari и т.п.) записи нет — только обычный журнал. Данные хранятся 14 дней (снимки) и 30 дней (события), потом удаляются автоматически.

## Установка — 3 шага

### 1. Обновить базу D1 (один раз)

Cloudflare Dashboard → Storage & Databases → D1 → база `pmt` → Console → вставить и выполнить весь текст файла `schema-session-recording.sql`. Создаются две таблицы (`rec_shots`, `rec_events`); ничего не удаляется.

### 2. Обновить Worker

Cloudflare Dashboard → Workers → `pmt-visitor-log` → Edit code. Откройте `cloudflare-worker.js` из этого архива, скопируйте ВЕСЬ текст и вставьте целиком вместо старого кода (сначала выделить всё Ctrl+A, потом вставить). Deploy.

Старый журнал посещений, пароль и блокировки не затрагиваются. В файле `src/` лежат исходники (`worker-template.js`, `admin.html`, `admin.js`); собранный файл уже готов, править его можно через `python3 build-worker.py` после правки исходников.

### 3. Обновить файлы сайта

Загрузите на хостинг с заменой: `visitor.js`, `loader.js`, `html2canvas.min.js` (новый файл, ~200 КБ). Остальные файлы не менялись. Кэш версий поднят до `20260926-rec1`.

## Как смотреть записи

1. Семь нажатий на нижнюю подпись сайта → `/admin` → пароль.
2. Вкладка «Записи сессий»: список сессий (дата, IP, страна, visitor, страницы, число кликов и снимков).
3. Клик по строке → просмотр: снимок с пронумерованными красными точками кликов; лента миниатюр внизу — переключение по времени; список всех кликов с элементом и координатами; клик по точке или строке синхронизирует вид.

## Замечания

- Запись не ведётся, пока Worker не обновлён (шаг 2) или таблицы не созданы (шаг 1) — клиент просто не получит подтверждение и не будет копить данные.
- Трафик: одна сессия передаёт до ~0,5–0,9 МБ снимков (отправка пакетами по 1 снимку, только после кликов/прокрутки). На лимиты Cloudflare это не влияет: free-тариф D1 (5 ГБ) при 100 сессиях в день займёт ~1–2% в сутки до автоочистки.
- Приватность: считаю правильным добавить строку об аналитике в `privacy.html` — сейчас файл пустой. Текст можно взять из секции «Что именно записывается» выше.
- На снимках отражается реальная вёрстка сайта; видеоплеер (Kinescope) на снимке выглядит как пустой блок — это ограничение html2canvas, не ошибка.
