Конфиденциальность

Обновлено 17.09.2026.

Сайт использует страну сетевого IP для регионального отображения материалов. Это не точная геолокация устройства. VPN и прокси могут менять определяемую страну.

Если владелец подключил сервер журнала Cloudflare Workers, при загрузке страницы браузер передаёт ему путь страницы. Сервер получает сетевой IP, страну и время запроса. Эти сведения сохраняются в Cloudflare D1 для диагностики и безопасности сайта. Имя, адрес электронной почты, точные координаты, содержимое форм, параметры адреса и история просмотра других сайтов не запрашиваются.

Журнал доступен владельцу после серверной авторизации. Записи старше 7 дней не отображаются; автоматическая очистка базы запускается каждый час. Резервные копии и технические журналы провайдеров могут иметь собственные сроки хранения. Пока сервер не подключён, встроенный журнал сайта не ведётся.

Если сервер не подключён или страна не определилась, браузер обращается к ipwho.is и ipapi.co. Эти сервисы получают ваш сетевой IP для определения страны. GitHub Pages, Cloudflare, Kinescope и внешние серверы изображений или шрифтов обрабатывают запросы по собственным правилам.

IP может быть общим для нескольких людей или принадлежать VPN. Запись не удостоверяет личность посетителя. Блокировщик, отключённый JavaScript или ошибка сети могут помешать записи. Журнал не используется для рекламного профилирования.

Выбранный язык сохраняется в браузере. Для входа владельца сервер использует временный защищённый cookie. Пароль и список IP не входят в публичные файлы сайта.

Конфіденційність

Оновлено 17.09.2026. Країна визначається за мережевим IP для регіонального відображення матеріалів, без точної геолокації пристрою. VPN або проксі можуть змінити результат.

Якщо власник підключив Cloudflare Worker, журнал безпеки зберігає IP, країну, шлях сторінки та час запиту у Cloudflare D1. Ім’я, електронна пошта, точні координати, дані форм, параметри адреси й історія інших сайтів не збираються. Доступ до журналу має власник після серверної авторизації.

Записи старші за 7 днів приховані, очищення бази запускається щогодини. Резервні копії та технічні журнали провайдерів можуть мати власні строки. Без підключеного сервера вбудований журнал не ведеться.

За відсутності сервера або визначеної країни використовуються ipwho.is та ipapi.co, які отримують мережевий IP. GitHub Pages, Cloudflare, Kinescope й зовнішні сервери зображень або шрифтів мають власні правила обробки даних.

Спільна мережа або VPN не дозволяють встановити особу за IP. Блокувальники, вимкнений JavaScript та збої мережі можуть перешкодити запису. Журнал не використовується для рекламного профілювання. Мова зберігається у браузері, а для входу власника використовується тимчасовий захищений cookie.
