# Обновление журнала устройства

В архиве теперь есть `cloudflare-worker.js`, в котором журнал выводит для каждого посещения:

- **Устройство** — `mobile`, `tablet` или `desktop`;
- **ОС** — определяемая браузером ОС;
- **Экран** — разрешение экрана в CSS-пикселях, например `1920x1080`;
- **DPR** — `devicePixelRatio`.

Клиентский `visitor.js` из этого проекта уже отправляет эти данные в `POST /visit` внутри объекта `device`.

## Что сделать в Cloudflare

1. Один раз выполнить `schema-device-migration.sql` в той же D1 базе, которая подключена к Worker.
2. Заменить код существующего Worker на `cloudflare-worker.js`.
3. Открыть `/admin` и войти в журнал.

Старые записи не удаляются. Для записей, созданных до миграции, новые поля будут отображаться как «Не определено».
