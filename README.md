# PMT ARCHIVE: современный сайт и режим совместимости

Статический сайт без установки зависимостей. Современные браузеры используют прежний дизайн. Браузеры без необходимых возможностей CSS автоматически получают упрощённый вариант, рассчитанный в том числе на Safari в iOS 6.

## Установка

1. Сделайте резервную копию сайта.
2. Распакуйте этот архив в папку существующего сайта с заменой одноимённых файлов.
3. **Не удаляйте исходную папку `assets/`.** В архив добавлена только новая обложка `assets/posters/komnata-razuma.jpg`. Существующие логотип, favicon, остальные постеры и файлы `assets/compat/` нужно сохранить на сайте.
4. Загрузите обновлённые файлы на хостинг, очистите его кэш и обновите страницу браузера.

Не ограничивайтесь заменой `script.js`: для совместимости нужны также обновлённые HTML, общий `data.js`, `compat.js`, `loader.js`, `script.legacy.js`, `legacy.css` и `assets/compat/`.

## Как выбирается версия

`compat.js` проверяет поддержку CSS Grid, CSS-переменных, `clamp()`, `aspect-ratio`, `padding-inline` и `inset`. Проверяется браузер, а не название ОС.

- При наличии этих возможностей загружается `script.js`, используется исходный дизайн и шрифт Onest.
- Иначе загружается ES5-скрипт `script.legacy.js`. К элементу `html` добавляется класс `legacy`, который включает запасную вёрстку.

В обновлении от 11.09.2026 к `styles.css` добавлены стили обложек и отметки «Новинка»; прежние правила сохранены. Все правила `legacy.css` ограничены классом `legacy` и не меняют современную версию. Современный сценарий сохраняет исходные анимации и эффекты. Изменения в его запуске нужны для последовательной загрузки скриптов, безопасного обращения к хранилищу и необязательных прямых видеофайлов.

`data.js` общий для обеих версий: проекты, эпизоды, словари и команда редактируются в одном месте. Он переведён в синтаксис ES5. При редактировании этого файла используйте `var`, обычные функции и обычные строки, не добавляйте стрелочные функции, `const`, `let`, spread, шаблонные строки и другие новые конструкции без повторной компиляции.

## Старые браузеры

В режиме совместимости используются обычные блоки, таблицы и float вместо Grid/Flexbox, фиксированные адаптивные размеры вместо CSS-переменных и `clamp()`. Сохранены тёмная палитра, фиолетовый акцент, проекты, серии, сезоны, титры и языки RU/UA. Тяжёлые анимации отключены, содержимое видно сразу.

Недоступное `localStorage` не блокирует запуск: язык дополнительно передаётся параметром `lang` в адресе и по внутренним ссылкам. Например: `project.html?p=savethefuture&lang=ua`. При полностью запрещённом хранилище возвращение на адрес без `lang` снова покажет выбор языка.

При ошибке загрузки изображения старая версия показывает локальную заглушку. Для настоящего постера `assets/posters/ben10-omniverse.webp` добавьте рядом JPEG-копию `assets/posters/ben10-omniverse.jpg`: старый Safari не умеет декодировать WebP. Исходного WebP во вложениях не было, поэтому конвертация не выполнялась. Новая версия продолжает использовать WebP, как раньше.

## Видео

Kinescope остаётся внешним сервисом. Переписывание сайта не добавляет поддержку старого Safari в чужой плеер и не исправляет несовместимые TLS-сертификаты сторонних серверов. В старой версии под плеером показывается только предупреждение: «Ваш браузер устарел видео может не запускаться.» Для украинского языка используется перевод. Дополнительные ссылки на Kinescope, прежний плеер и видеофайл удалены.

Для независимого от Kinescope воспроизведения можно добавить к серии или трейлеру `mp4` и/или `hls`, содержащие реальные адреса файлов. Пример структуры, пути нужно заменить на существующие:

````javascript
{
  n: '1 эпизод',
  title: 'Название серии',
  kinescope: 'существующий-id',
  poster: 'assets/posters/example.jpg',
  mp4: 'media/episode-1.mp4',
  hls: 'media/episode-1.m3u8'
}
````

При наличии прямого адреса обе версии показывают встроенный HTML5 `<video>` с управлением. Если прямых адресов нет, поведение Kinescope на современных устройствах не меняется. Поля `mp4` и `hls` в поставляемом каталоге не заполнены: исходные видео не были предоставлены.

Для очень старых устройств подойдёт отдельная совместимая копия MP4, например H.264 Baseline с AAC-LC, 640×360, до 30 кадров/с. Итоговое воспроизведение нужно проверить на конкретном устройстве. Серверу нужны корректный MIME-тип `video/mp4` и поддержка HTTP Range; HLS требует совместимых плейлистов и сегментов. Автовоспроизведение на старом iOS не гарантируется, запуск выполняется пользователем.

## Проверки и ограничения

Автоматические проверки описаны в `COMPATIBILITY.md`. Настоящий Safari в iOS 6 в этой среде не запускался. Совместимость конкретного хостинга, оригинальных изображений и внешнего видео требует проверки на устройстве.

Если iOS не может установить HTTPS-соединение с самим сайтом, JavaScript и CSS ещё не загружены и исправить это внутри страницы нельзя. Нужны совместимые настройки HTTPS и цепочка сертификатов на стороне хостинга.
