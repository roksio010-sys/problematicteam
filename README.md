# PMT ARCHIVE (архив 2022–2026) — сайт Problematic Team

Статический сайт без сборки и зависимостей: HTML + CSS + один JS-файл.
Открывается двойным кликом по `index.html` и так же разворачивается на GitHub Pages /
Netlify / любом хостинге — просто загрузи папку целиком (вместе с `assets/`).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: герой, о команде, проекты, команда |
| `projects.html` | Архив: сетка всех проектов |
| `project.html` | Страница проекта, `?p=<id>` |
| `watch.html` | Отдельная страница серии, `?p=<id>&e=<номер>` |
| `data.js` | **Весь контент и оба языка**: `UI`, `DICT`, `WHY`, `TEAM`, `PROJECTS` |
| `script.js` | Язык, рендер, модальный плеер, плавный скролл, анимации |
| `styles.css` | Оформление и адаптив |
| `assets/pmt.png` | Логотип PMT (фиолетовый, из присланного файла) |
| `assets/favicon.png` | Иконка сайта |

## Языки (RU / UA)

- При первом входе показывается экран «Выбери язык / Обери мову». Выбор хранится
  в `localStorage` (`pmt-lang`), сменить можно кнопками **RU / UA** в шапке.
- Длинные тексты лежат как `{ ru: '...', ua: '...' }`.
- Короткие строки (роли, персонажи, ключи мета, названия серий) переводятся
  через словарь `DICT` в `data.js`: добавил русскую строку как ключ — получил перевод.
  Если строки нет в словаре, показывается оригинал, сайт не ломается.

## Как менять контент

- **Текст, мета, актёры проекта** — блок проекта в массиве `PROJECTS`.
- **Добавить серию** — новый объект в `episodes`.
- **Вставить видео** — поле `kinescope` (только id из `kinescope.io/embed/<id>`).
  Пустая строка = «Серия в производстве»; если задан `fallback`, ведёт на старый плеер.
- **Люди в разделе «Команда»** — массив `TEAM`.
- **Подписи интерфейса** — объект `UI`.

Серия открывается кнопкой «Открыть серию» — плеер разворачивается на весь экран
поверх страницы (Esc или крестик — закрыть).

Если у серии `credits: null`, титры на `watch.html` берутся из состава проекта,
чтобы не показывать неверных актёров.
